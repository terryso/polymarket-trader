## 1. 产品概述

### 1.1 产品愿景

**Polymarket Trader** 是一个部署在 Mac Mini 上的 LLM 驱动自动交易系统，24/7 运行，追求稳定可靠的小额收益。

### 1.2 核心价值主张

| 维度 | 描述 |
|------|------|
| **自动化** | 全自动运行，无需人工干预 |
| **智能化** | LLM 驱动的概率分析和决策 |
| **稳定性** | 严格风险控制，追求稳定收益 |
| **轻量级** | 本地部署，不依赖复杂数据管道 |

### 1.3 目标用户

| 用户类型 | 描述 |
|----------|------|
| **主要用户** | 想要在预测市场获得被动收入的个人 |
| **特征** | 有一定技术背景，拥有 Mac Mini，希望自动化投资 |

## 4. 风险控制规则

### 4.1 资金管理

```yaml
capital:
  initial: 200           # 初始资金 $200
  max_single_ratio: 0.20 # 单笔最大 20% ($40)
  min_bet: 5             # 单笔最小 $5
```

### 4.2 熔断机制

```yaml
circuit_breaker:
  consecutive_losses: 3    # 连续亏损 3 次
  reduce_ratio_to: 0.10    # 降到 10% 下注
  daily_loss_limit: 0.30   # 日亏损 30% 停止
  capital_threshold: 100   # 资金低于 $100
  capital_reduce_to: 0.10  # 降到 10% 下注
```

### 4.3 置信度门槛

```yaml
confidence:
  min_to_trade: 0.75    # LLM 置信度至少 75%
  min_edge: 0.10        # 与市场价格差距至少 10%
```

### 4.4 持仓限制

```yaml
position:
  max_per_market: 0.40  # 单市场不超过 40%
  max_open_markets: 3   # 最多同时持有 3 个市场
```

## 5. 市场筛选规则

### 5.1 目标领域

| 领域 | 包含 | 排除 |
|------|------|------|
| 政治 | ✅ 选举、法案、政策 | ❌ 纯猜测性 |
| 商业 | ✅ 收购、IPO、人事 | ❌ 内幕信息类 |
| 科技 | ✅ 产品发布、里程碑 | ❌ 纯炒作 |
| 经济 | ✅ 利率、通胀、就业 | ❌ 高频数据 |
| 加密货币 | ✅ 长期趋势、监管事件 | ❌ 短期价格预测 |

### 5.2 筛选条件

```yaml
good_market_criteria:
  - 截止日期 > 7天
  - 流动性 > $10,000
  - 条款清晰无歧义
  - 可用逻辑推理分析

skip_if:
  - 标题包含 "price" "USD" "tomorrow"
  - 流动性 < $5,000
  - 截止日期 < 3 天
  - 描述中有争议性条款
```
