# Lovable 提示词 - Polymarket Trader Dashboard

## 项目概述

创建一个 **Polymarket Trader Dashboard** - 一个预测市场自动交易系统的监控面板。

这是一个本地部署的交易系统，用户需要一个 Web Dashboard 来监控：
- 系统运行状态
- 交易收益/PnL
- 当前持仓
- 预测历史和准确率
- 风险控制状态

---

## 技术栈要求

```
- React 18
- TypeScript
- Tailwind CSS
- shadcn/ui 组件库
- Recharts (图表)
- React Router (路由)
- TanStack Query (数据获取)
```

---

## 设计风格

- **风格**: 现代、专业、金融科技感
- **色调**: 深色主题为主（可选浅色切换）
- **主色**: 深蓝/深灰背景，绿色（盈利），红色（亏损）
- **布局**: 左侧导航栏 + 主内容区
- **卡片**: 带阴影的圆角卡片
- **字体**: Inter 或类似现代无衬线字体

---

## 页面结构

### 1. 首页 (Home) - `/`

**布局**: 顶部统计卡片 + 中间图表 + 底部最近活动

**统计卡片 (4个一行)**:
```
┌─────────────┐ ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│  💰 总资金   │ │  📈 今日PnL │ │  🎯 胜率    │ │  ⚡ 系统状态│
│  $200.00    │ │  +$5.50     │ │  65.5%      │ │  🟢 运行中  │
│  +2.75%     │ │  +2.75%     │ │  33/50      │ │  2h 30m     │
└─────────────┘ └─────────────┘ └─────────────┘ └─────────────┘
```

**PnL 图表**:
- 7天/30天收益曲线图
- 使用 Recharts AreaChart
- 绿色填充（正值），红色填充（负值）

**最近活动**:
- 最近5条交易/预测记录
- 显示时间、市场名称、操作类型、金额

---

### 2. 持仓页面 (Positions) - `/positions`

**布局**: 表格展示当前持仓

**表格列**:
| 市场名称 | 方向 | 份额 | 成本价 | 当前价 | PnL | 操作 |
|----------|------|------|--------|--------|-----|------|
| 特朗普胜选 | YES | 50 | $0.65 | $0.70 | +$2.50 | [详情] |

**功能**:
- 表格可排序、筛选
- PnL 正数绿色，负数红色
- 总持仓价值汇总显示在顶部

---

### 3. 交易历史 (Trades) - `/trades`

**布局**: 筛选器 + 表格

**筛选器**:
- 模式: [All] [Paper] [Live]
- 类型: [All] [Buy] [Sell]
- 日期范围选择

**表格列**:
| 时间 | 市场 | 类型 | 模式 | 金额 | 价格 | 份额 | 状态 |
|------|------|------|------|------|------|------|------|
| 2026-02-15 10:30 | 特朗普胜选 | BUY YES | Paper | $10.00 | $0.65 | 15.38 | ✅ |

**分页**: 每页20条

---

### 4. 预测记录 (Predictions) - `/predictions`

**布局**: 统计卡片 + 表格

**统计卡片**:
```
┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│  📊 总预测   │ │  ✅ 正确    │ │  ❌ 错误    │

│             │ │  66%        │ │  34%        │
```

| 时间 | 市场 | LLM预测 | 市场价格 | 置信度 | 结果 | 状态 |
|------|------|---------|----------|--------|------|------|
| 2026-02-15 | 特朗普胜选 | 75% YES | 65% YES | 高 | - | 待验证 |

### 状态指示器

- 🟢 运行中 (绿色)
- 🟡 暂停 (黄色)
- 🔴 停止 (红色)

### 模式切换器

- Paper Trading (蓝色标签)
- Live Trading (红色标签，带警告)
