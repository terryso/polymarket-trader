## 核心愿景

### 产品定位

**Polymarket Trader** 是一个部署在 Mac Mini 上的 LLM 驱动自动交易系统，24/7 运行，追求稳定可靠的小额收益而非高风险高回报。

### 核心价值主张

| 维度 | 决定 |
|------|------|
| **目标** | 全自动 LLM 驱动的 Polymarket 交易 |
| **部署** | Mac Mini 本地 24/7 运行 |
| **策略** | 稳定赚钱 > 高风险高回报 |
| **数据** | 最小化外部数据，依赖 LLM 推理 + 实时 API |

## Technique 2: First Principles Thinking（第一性原理）

### 核心洞察

| # | 洞察 | 含义 |
|---|------|------|
| 1 | 价格 = 市场概率估计 | 市场可能是错的 |
| 2 | 盈利 = 你比市场更准 | 找差距，不是赌运气 |
| 3 | LLM = 概率估计器 | 用 LLM 提供另一个视角 |
| 4 | 聚焦可推理问题 | 发挥 LLM 优势，避开劣势 |

### 盈利公式

```
盈利 = (真实概率 - 市场价格) × 下注金额

系统需要：
1. 找到真实概率 ≠ 市场价格的机会
2. 用 LLM 估计真实概率
3. 只在差距足够大时下注
4. 控制下注金额避免破产
```

### 目标领域

| 领域 | 适合原因 |
|------|----------|
| ✅ 政治 | 程序性事件、可推理 |
| ✅ 商业 | 收购、IPO、可预测 |
| ✅ 科技 | 产品发布、里程碑 |
| ✅ 经济 | 利率、通胀、数据类 |
| ✅ 加密货币（筛选后） | 长期趋势、监管事件、里程碑 |
| ❌ 短期价格预测 | 需要实时信息 |
| ❌ 纯投机/炒作 | 无逻辑可循 |

## 风险控制配置

### 核心参数

```yaml
# risk_config.yaml

capital:
  initial: 200           # 初始资金 $200
  max_single_ratio: 0.20 # 单笔最大 20% ($40)
  min_bet: 5             # 单笔最小 $5

# 熔断机制
circuit_breaker:
  consecutive_losses: 3    # 连续亏损 3 次
  reduce_ratio_to: 0.10    # 降到 10% 下注
  daily_loss_limit: 0.30   # 日亏损 30% 停止
  capital_threshold: 100   # 资金低于 $100
  capital_reduce_to: 0.10  # 降到 10% 下注

# 置信度门槛
confidence:
  min_to_trade: 0.75    # LLM 置信度至少 75%
  min_edge: 0.10        # 与市场价格差距至少 10%

# 持仓限制
position:
  max_per_market: 0.40  # 单市场不超过 40%
  max_open_markets: 3   # 最多同时持有 3 个市场
```

### 风险模拟

```
$200 起始资金，每次下注 20%，连续亏损场景：

第 1 次：$200 - $40 = $160  (亏损 20%)
第 2 次：$160 - $32 = $128  (累计亏损 36%)
第 3 次：$128 - $26 = $102  (累计亏损 49%) → 触发熔断！
```
